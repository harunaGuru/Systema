## D. Implementation Requirements

### 1. Initialize Next.js 16

Note: if Next.js is installed, ensured it in Next.js 16 if yes then skip this part and move to the next if not uninstall the nextjs and continue

Use the official `create-next-app` flow targeting Next.js 16. Accept the prompts as follows, unless the CLI version does not offer a choice:

- TypeScript: **Yes**
- ESLint: **Yes**
- Tailwind CSS: **Yes** (v4)
- `src/` directory: **No** (use root `app/`)
- App Router: **Yes**
- Import alias: `@/*`

Do not use `--no-agents-md`. The `AGENTS.md` managed block is already present in the repository; `next dev` will preserve content outside the block.

If `create-next-app` scaffolds a `CLAUDE.md` that duplicates `AGENTS.md`, leave it; it is harmless and the managed block is the shared source.

### 2. TypeScript configuration

Open `tsconfig.json` and ensure the `compilerOptions` include:

```json
{
  "strict": true,
  "noUncheckedIndexedAccess": true,
  "noFallthroughCasesInSwitch": true,
  "useUnknownInCatchVariables": true
}
```
