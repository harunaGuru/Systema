## C. Context and Dependencies

- **Prerequisites:** AI-002 complete and verified (the task exists and works).
- **Contract introduced:** The `/api/ai/generate` endpoint and the functional Prompt tab.
- **Contract consumed:** `generateGraphTask`, `SystemaGraphSchema`, Liveblocks `useMutation`.
- **Approved decisions:**
  - **Invariant #2:** The AI task runs in Trigger.dev, never inline in the Next.js route. The route only triggers the task and returns the run ID.
  - **Applying the graph:** The client must NOT replace the entire canvas. It must **append** the generated nodes and edges to the existing Liveblocks Storage, or replace it if the prompt implies a full generation. For simplicity in this unit, append the new nodes/edges to the existing canvas.
  - **Status handling:** The UI must show distinct states: Idle, Generating (loading), Success, and Error.
  - **Liveblocks Mutation:** Since the canvas is wrapped in `LiveblocksRoom`, the AI Sidebar (rendered inside the shell) can use `useMutation` to push new nodes to the `flow` storage.

## D. Implementation Requirements

### 1. Create `app/api/ai/generate/route.ts`

Create a Route Handler that validates the request and triggers the task.

START OF route.ts snippet

    import { NextResponse } from "next/server";
    import { auth } from "@clerk/nextjs/server";
    import { tasks } from "@trigger.dev/sdk/v3";
    import { generateGraphTask } from "@/trigger/generate-graph";
    import { requireProjectAccess } from "@/lib/server/auth";

    export async function POST(req: Request) {
      try {
        const { userId } = await auth();
        if (!userId) return NextResponse.json({ error: "Unauthorized" }, { status: 401 });

        const body = await req.json();
        const { projectId, prompt, currentGraph } = body;

        if (!projectId || !prompt) {
          return NextResponse.json({ error: "Missing projectId or prompt" }, { status: 400 });
        }

        // Enforce access (Invariant #1)
        await requireProjectAccess(projectId);

        // Trigger the task (Invariant #2)
        const handle = await tasks.trigger<typeof generateGraphTask>("generate-graph", {
          projectId,
          prompt,
          currentGraph,
        });

        return NextResponse.json({ success: true, runId: handle.id });
      } catch (error: any) {
        console.error("AI Route Error:", error);
        return NextResponse.json({ error: error.message || "Internal error" }, { status: 500 });
      }
    }

END OF route.ts snippet

### 2. Update `components/editor/ai-sidebar.tsx`

The right sidebar currently has a placeholder for the "Prompt" tab. Replace it with a functional component:

- **State:** `prompt` (string), `status` ('idle' | 'generating' | 'success' | 'error'), `errorMessage` (string).
- **Liveblocks Mutation:**
  START OF mutation snippet
  import { useMutation } from "@liveblocks/react";
  const applyGraph = useMutation(({ storage }, newNodes, newEdges) => {
  const flow = storage.get("flow");
  const nodes = flow.get("nodes");
  const edges = flow.get("edges");
  // Append new nodes and edges
  newNodes.forEach(n => nodes.push(n));
  newEdges.forEach(e => edges.push(e));
  }, []);
  END OF mutation snippet

- **Submit Handler:**
  1. Set status to 'generating'.
  2. `fetch('/api/ai/generate', { method: 'POST', body: JSON.stringify({ projectId, prompt }) })`.
  3. If the fetch fails, set status to 'error'.
  4. If the fetch succeeds, you have the `runId`. Use the Trigger.dev React hooks or `useRealtimeRun` (from `@trigger.dev/react-hooks`) to poll for the task completion. Alternatively, use `setInterval` to fetch the run status from a GET route or `trigger.dev`'s SDK. _(Note: If real-time hooks are too complex for this unit, use a simple polling mechanism every 2 seconds to check the run status via the Trigger.dev API)._
  5. When the run succeeds and returns `{ success: true, graph }`, call `applyGraph(graph.nodes, graph.edges)`.
  6. Set status to 'success'.

- **UI Layout:**
  - A `<Textarea>` for the prompt.
  - A `<Button>` "Generate" (disabled when loading or prompt is empty).
  - A status area: show a loading spinner/text when generating, a green success message, or a red error message.
  - Place this inside the `TabsContent` for the "Prompt" tab.
