# UI-002 — Design System Foundation (shadcn/ui + globals.css)

## A. Identity and Objective

- **Feature ID:** UI-002
- **Title:** Design System Foundation (shadcn/ui + globals.css)
- **Primary objective:** Initialize shadcn/ui on the existing Next.js 16 scaffold and replace the default `app/globals.css` with the approved Systema design tokens from `ui-context.md`, producing a themed application shell that later units can build on.
- **Expected outcome:** shadcn/ui CLI is configured and working, `components/ui/` contains the initial primitives installed in this unit, `lib/utils.ts` exports a working `cn()` helper, `app/globals.css` contains the Systema tokens, and a sample page demonstrates that `bg-surface`/`text-primary` resolve to the approved dark theme values.
- **References:** `planning/feature-map.md` UI-002; `context/ui-context.md` Theme, Colors, Typography, Border Radius, Component Library; `context/code-standards.md` Styling; `AGENTS.md`.

## B. Execution Contract

The agent must do all of the following without asking the user for confirmation, in this order:

1. Read `AGENTS.md`, `context/ui-context.md` (Theme, Colors, Typography, Border Radius, Component Library), `context/code-standards.md` (Styling).
2. Confirm UI-001 is in place: `app/globals.css` exists with `@import "tailwindcss";`, `tsconfig.json` has strict flags, `npm run build` passes.
3. Initialize shadcn/ui with `npx shadcn@latest init`, choosing Neutral base color, CSS variables yes, New York style, `app/globals.css` as the global CSS file, `components` as the components directory, `lib/utils` as the utils directory, React Server Components yes.
4. Install the seven primitives with `npx shadcn@latest add button card dialog input tabs textarea scroll-area`.
5. Replace `app/globals.css` with the Systema token block in D.3.
6. Verify `lib/utils.ts` matches D.4.
7. Replace `app/page.tsx` with the sample page described in D.5.
8. Run the **Checks** block in Section I top to bottom.
9. Fix any in-scope failure and re-run the failing check.
10. Report PASS or FAIL per Section J. On PASS, state that the agent has stopped and is awaiting the next feature. On FAIL, state the exact blocker and stop.

Do not install any other package. Do not modify `app/layout.tsx` or `components/ui/*`.

## C. Context and Dependencies

- **Prerequisites:** UI-001 complete and verified.
- **Contract introduced:** the Systema design token set in `app/globals.css`. Every UI unit from UI-004 onward consumes these tokens by Tailwind utility name. Token names must not change in later units without a controlled change to this specification.
- **Contract consumed:** shadcn/ui's `cn()` helper in `lib/utils.ts`.
- **Approved decisions:** shadcn/ui only (`ui-context.md`). Tokens are OKLCH, exposed via `@theme inline`. No hardcoded colors in components (`code-standards.md` Styling). Lucide is installed later, in UI-004, not here.

Run `npx shadcn@latest init` and choose the options listed in B.3. If the installed CLI version offers different prompts, choose the closest equivalents and record the actual choices in the report.

### 4. Verify `lib/utils.ts`

`lib/utils.ts` must contain exactly this content:

    import { clsx, type ClassValue } from "clsx"
    import { twMerge } from "tailwind-merge"

    export function cn(...inputs: ClassValue[]) {
      return twMerge(clsx(inputs))
    }

If the file is missing or different, correct it. Do not add other utilities to `lib/utils.ts` in this unit.

### 5. Replace `app/page.tsx` with a sample page

The page must render:

- A `<main>` with `min-h-screen bg-bg-base text-text-primary p-8 space-y-8`.
- A heading "Systema design system".
- A paragraph using `text-text-muted`.
- A row of shadcn `<Button>` variants: default, secondary, outline, ghost, destructive, each wrapped in `bg-bg-surface p-2 rounded-md`.
- A shadcn `<Card>` with `CardHeader`, `CardTitle`, `CardContent` and placeholder text.
- A shadcn `<Dialog>` with a trigger Button labeled "Open dialog"; the dialog contains a title, description, and a "Close" button.
- A shadcn `<Tabs>` with two `<TabsTrigger>` values `owner` and `shared`, labels "Owner" and "Shared", each `<TabsContent>` showing "No projects yet." in `text-text-muted`.

All text must be readable against the dark background. If any text is unreadable, the token mapping is wrong; fix the mapping, not the text color.
